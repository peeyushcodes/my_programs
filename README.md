# Programming Practice

A collection of beginner-friendly programming exercises and examples, primarily written in C++. The repository is used to practice programming fundamentals, problem solving, data structures, and object-oriented programming.

## Repository structure

```text
.
├── cpp/       # C++ practice programs
└── python/    # Python practice programs
```

## C++ topics

The `cpp` directory currently includes examples covering:

- Arrays and array manipulation
- Bitwise operations
- Functions and function overloading
- Inline functions
- Linked lists
- Recursion and number reversal
- Sorting
- Scope resolution
- Object-oriented programming
- LeetCode-style problem solving

Each source file is a standalone example and can be compiled independently.

## Running a C++ program

Using `g++`:

```bash
g++ cpp/linked_list2.cpp -o linked_list2
./linked_list2
```

On Windows PowerShell:

```powershell
g++ .\cpp\linked_list2.cpp -o .\linked_list2.exe
.\linked_list2.exe
```

Replace `linked_list2.cpp` with the source file you want to run.
